# traces

Five trace files for `radb-storage trace --policy lru|clock --json`.

The Module 1 handout says the graded traces are published with it, but they were
not in this repository, so `generate.sh` builds five deterministic stand-ins of
the same character:

| file | shape | length |
|------|-------|-------:|
| `trace1.txt` | uniform over 256 pages | 1000 |
| `trace2.txt` | cyclic scan of a 50-page file, 20 passes | 1000 |
| `trace3.txt` | sequential scan of an 80-page file, 10 passes | 800 |
| `trace4.txt` | uniform over 512 pages | 2000 |
| `trace5.txt` | 90% in a 16-page hot set, 10% cold over 256 pages | 1000 |

They are generated by a Lehmer LCG so the files are reproducible:

```
./generate.sh
```

If the official files are supplied, drop them in as `trace1.txt` … `trace5.txt`
(or point `--file` at them); the `trace` command and the report's method do not
change. Each file is one unsigned page id per line; blank lines are skipped.
